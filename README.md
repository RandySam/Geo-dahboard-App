# GeoDashboard Web Application

## Description
Web-based Geographic Information System (GIS) platform for visualizing and performing simple spatial analysis on shapefile data.

## Tech Stack
- Frontend: React 
- Backend: Node.js, Express.js
- Database: PostgreSQL
